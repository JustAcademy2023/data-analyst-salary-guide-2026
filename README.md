# Data Analyst Salary Guide 2026

A playful, responsive landing page that walks freshers and experienced professionals through data analyst pay in India: an interactive salary meter, a five level ladder, skill cards for Tableau, Power BI and Python, and links to the JustAcademy Data Analytics Bootcamp in Mumbai.

## Preview

Open `index.html` in any browser, or enable GitHub Pages (Settings, Pages, deploy from the `main` branch, root folder).

## Features

Single file, no build step, no dependencies. Responsive layout, sticky header, animated ticker, interactive slider and fully clickable course and blog links.

## Customise

Colours live in the `:root` block of `index.html`. Salary levels live in the `L` array at the bottom of the file.

## Note

Salary ranges are indicative and vary by city, company and skills.
